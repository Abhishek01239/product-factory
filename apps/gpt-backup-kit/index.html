Custom GPTs retire on Dec 11, 2026 · —

Save your custom GPT before it stops running.

OpenAI is replacing custom GPTs with plugins. "Migrate to plugin" moves instructions, knowledge files and connected apps, but custom actions, the chosen model, sharing settings and unpublished edits stay behind. OpenAI has no export button for GPTs. This kit gives you one: paste your GPT's configuration and download a complete backup, a checklist for your GPT, and starter code to rebuild its actions.

      FAQ
      
      
      When exactly do custom GPTs stop working?
      OpenAI's FAQ says custom GPTs are scheduled to retire on Dec 11, 2026 across ChatGPT plans, when GPTs and their pages become inaccessible. Enterprise workspaces with a qualified, approved deferral get Feb 11, 2027. Follow the notice for your own account or workspace.
      
      
      Should I still use OpenAI's "Migrate to plugin"?
      Yes, if you want to keep using it in ChatGPT. This kit doesn't replace migration; it makes sure you keep a copy of everything, including the parts migration leaves behind, and gives you a checklist to test the result. Migration uses your latest published version and makes the original read-only, so publish edits and back up first.
      
      
      Does this connect to my ChatGPT account?
      No. There is no login and no server. You copy fields from the GPT editor yourself; the page builds the files in your browser. The page's security policy blocks it from sending data to other sites.
      
      
      What is SKILL.md?
      A Markdown file with a short YAML header (name and description), defined by the open Agent Skills specification. OpenAI says migrated instructions become a skill. The generated file is a portable copy you can keep, edit, or use with tools that read Agent Skills.
      
      
      Will the MCP stub just work?
      It's a starting point. Each operation in your action's OpenAPI schema becomes one tool that calls the same API, with the key read from an environment variable. We tested generated stubs with MCP Python SDK v1 and v2. You still need to review it, host it securely if a remote assistant should reach it, and check your plan supports custom MCP connections.
      
      
      What about my past chats with the GPT?
      OpenAI says existing conversations stay accessible after retirement. To keep your own copy, use ChatGPT's Settings → Data controls → Export data.
