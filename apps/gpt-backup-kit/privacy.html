Privacy

GPT Backup Kit is a static page. It has no server-side code, no accounts, no cookies and no analytics.

  • Everything you type is processed by JavaScript in your browser. The page's Content Security Policy blocks connections to other sites.
  • Your text fields are saved in your browser's localStorage so a reload doesn't lose work. Clear all deletes them.
  • Knowledge files you add are held in memory only and written into the ZIP you download. They are never stored or uploaded.
  • The page is hosted on GitHub Pages, which may keep standard server logs (such as IP address) as described in GitHub's privacy statement.
  • Don't paste API keys or passwords. The kit warns you if it spots something that looks like one.
