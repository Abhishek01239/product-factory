Sonnet 4.5 retires Nov 30, 2026

Find the Claude API calls that return 400 after you switch to 5.5.

Changing the model string is not enough. Sonnet 5.5 and Opus 5.5 reject assistant prefill, non-default temperature, thinking budgets, forced tool_choice and thinking: disabled. Haiku 5.5 rejects most of those too, but still allows forced tools. Paste a request, some code or a public repo and see exactly which lines fail, and get a corrected request.

Why a model swap breaks working code

Settings that used to be fine now fail

Code written for Sonnet 4.5 or Haiku 4.5 often sends a prefilled { to force JSON, a temperature, or a budget_tokens thinking budget. All three return HTTP 400 on the 5.5 models.

The rules differ per model

Forced tool_choice fails on Sonnet 5.5 and Opus 5.5 but works on Haiku 5.5. between_tools exists only on Sonnet 5.5. Bedrock has no strict tools for these models. Generic checklists blur this.

Responses change shape

Thinking now runs by default, so content[0] can be a thinking block. Code that reads content[0].text silently gets the wrong thing.

      FAQ
      
  
      Does this send my code or prompts anywhere?
      No. Everything runs in your browser. The only network requests are to GitHub, and only when you scan a public repo. See the privacy note.
      
  
      How is this different from Anthropic's /claude-api migrate skill?
      That skill runs inside Claude Code and edits your files. This page is a free, read-only pre-check: no install, no API key, no edits. It is useful for reviewing a pull request, checking a library you depend on, or seeing the per-model differences before you pick a target.
      
  
      How accurate is the code scan?
      The JSON check is exact for the rules listed above. The code scan is line-based and can miss settings built dynamically, or flag a temperature that goes to another provider. Treat warnings as "look here".
      
  
      What can't it detect?
      Edited conversation history (thinking blocks must be replayed unchanged on new accounts), refusals, cost changes from the new tokenizer (~30% more tokens), and anything only visible at runtime. Those appear as notes.
      
  
      Is this affiliated with Anthropic?
      No. It is an independent, open-source tool built from Anthropic's public documentation. Claude is a trademark of Anthropic.
