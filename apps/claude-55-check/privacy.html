5.5 Request Check

Privacy

Claude 5.5 Request Check is a static page. It has no server-side code, no accounts, no cookies and no analytics. It never asks for an API key.

  • Request bodies, code and files you paste or choose are analysed by JavaScript in your browser and are never uploaded. Prompts inside a pasted request stay on your device.
  • When you scan a public repository, your browser requests the repository info and file list from api.github.com and the files from raw.githubusercontent.com. Those are the only external connections the page's Content Security Policy allows. No token is used.
  • Nothing is stored: results disappear when you close the tab. A service worker caches the page's own static files so it loads offline.
  • The page is hosted on GitHub Pages, which may keep standard server logs (such as IP address) as described in GitHub's privacy statement.
