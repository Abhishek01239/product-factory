Runner 26 Check

Privacy

Ubuntu 26 Runner Check is a static page. It has no server-side code, no accounts, no cookies and no analytics.

  • Workflow files you paste or upload are analysed by JavaScript in your browser and are never uploaded.
  • When you enter a public repository, your browser requests its .github/workflows listing from api.github.com and the files from raw.githubusercontent.com. Those are the only external connections the page's Content Security Policy allows. No token is used or requested.
  • Nothing is stored: results disappear when you close the tab. A service worker caches the page's own static files so it loads offline.
  • The page is hosted on GitHub Pages, which may keep standard server logs (such as IP address) as described in GitHub's privacy statement.
