ubuntu-latest moves to Ubuntu 26.04 from Oct 19, 2026

Find the CI steps that break when ubuntu-latest becomes 26.04.

GitHub is moving every ubuntu-latest job to Ubuntu 26.04 between Oct 19 and Nov 19, 2026. The new image drops Java 8, Clang 16–18, GCC 12, Miniconda, Swift, Julia, Fastlane, Pulumi and the global tsc, webpack and lerna commands, and bumps CMake to 4, Compose to 5 and MySQL to 8.4. This tool reads your workflows and points at the exact lines.

Check your workflows

Add a public repo, paste a workflow, or upload files from .github/workflows/. Azure Pipelines YAML with vmImage: ubuntu-latest works too.

Reads .github/workflows through GitHub's public API (60 requests an hour per IP, no token). Add /tree/branch to check a branch. For private repos, paste or upload instead.

The canary workflow runs on ubuntu-24.04 and ubuntu-26.04 side by side and reports which tools are missing. Each file also has a “Pinned copy” download with ubuntu-latest replaced by ubuntu-24.04: that buys time but doesn't fix the job.

FAQ

Should I just pin ubuntu-24.04?

It's a reasonable short-term fix for jobs the checker marks "Likely to break". 24.04 stays supported for now, but it will eventually be deprecated like 22.04 (unsupported from Apr 17, 2027). Pin to buy time, then fix the job with the setup actions the checker suggests.

How accurate is this?

The checker reads YAML statically. It knows which tools left the image and which steps set up their own versions (setup-java, setup-python, setup-node, setup-miniconda, mise and others). It can't see inside scripts you call (./build.sh), local composite actions or containers, and it can't resolve every expression. Treat findings as a checklist, then run the canary workflow to confirm.

Does my code leave my browser?

No. Pasted and uploaded files are analysed locally. For public repos, your browser fetches the workflow files directly from api.github.com and raw.githubusercontent.com. There is no server, no analytics and nothing is stored. See privacy.

Can I test on 26.04 before the switch?

Yes. The ubuntu-26.04 label is generally available now. Download the canary workflow, commit it, and run it from the Actions tab, or change one job's runs-on to ubuntu-26.04 in a pull request.

What about Azure DevOps?

Microsoft-hosted vmImage: ubuntu-latest agents use the same images and follow the same move. Paste azure-pipelines.yml and the checker scans script and bash steps.
