Supabase Grants Check

Privacy

Supabase Grants Check is a static page. It has no server-side code, no accounts, no cookies and no analytics.

  • Files you choose or paste (SQL migrations, config.toml, source code) are analysed by JavaScript in your browser and are never uploaded.
  • The page never asks for your Supabase URL, anon key, service_role key or database password, and cannot connect to your database. The optional snapshot is a read-only query you run yourself in the Supabase SQL Editor; it returns table, policy and function names with their grants, not row data. You decide whether to paste it.
  • When you check a public repository, your browser requests the repository info and file list from api.github.com and the files from raw.githubusercontent.com. No token is used. These two hosts are the only external connections the page's Content Security Policy allows.
  • Nothing is stored: results disappear when you close the tab. A service worker caches the page's own static files so it loads offline.
  • The page is hosted on GitHub Pages, which may keep standard server logs (such as IP address) as described in GitHub's privacy statement.
