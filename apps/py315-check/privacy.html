Py 3.15 Check

Privacy

Python 3.15 Readiness Check is a static page. It has no server-side code, no accounts, no cookies and no analytics.

  • Files you choose or paste (requirements files, lockfiles, pyproject.toml, Python code, workflows, Dockerfiles) are analysed by JavaScript in your browser and are never uploaded.
  • With "Look up wheels on pypi.org" switched on, your browser asks pypi.org for the public file list of each pinned package, and of flagged packages to find the smallest upgrade. Only package names and versions are sent. Switch it off to stay offline; uv.lock, poetry.lock and pylock.toml are still checked from the wheel names they contain.
  • When you scan a public repository, your browser requests the repository info and file list from api.github.com and the files from raw.githubusercontent.com. No token is used. These three hosts are the only external connections the page's Content Security Policy allows.
  • Nothing is stored: results disappear when you close the tab. A service worker caches the page's own static files so it loads offline.
  • The page is hosted on GitHub Pages, which may keep standard server logs (such as IP address) as described in GitHub's privacy statement.
