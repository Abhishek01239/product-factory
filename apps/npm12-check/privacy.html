npm 12 Check

Privacy

npm 12 Readiness Check is a static page. It has no server-side code, no accounts, no cookies and no analytics.

  • Files you choose or paste (package-lock.json, package.json, .npmrc, CI files) are analysed by JavaScript in your browser and are never uploaded. Tokens that may sit in a pasted .npmrc stay on your device.
  • With "Look up each flagged package's actual install script" switched on, your browser asks registry.npmjs.org for the public manifest of each package that has an install script. Only package names and versions are sent. Switch it off to stay fully offline.
  • When you scan a public repository, your browser requests the repository info and file list from api.github.com and the files from raw.githubusercontent.com. No token is used. These three hosts are the only external connections the page's Content Security Policy allows.
  • Nothing is stored: results disappear when you close the tab. A service worker caches the page's own static files so it loads offline.
  • The page is hosted on GitHub Pages, which may keep standard server logs (such as IP address) as described in GitHub's privacy statement.
