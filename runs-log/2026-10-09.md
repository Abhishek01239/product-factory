## Gotchas
- Background processes in the sandbox die between bash calls: start mock servers and their clients in the same command (or use the server-start helper).
- `scripts/scan_secrets.py` flags fake tokens in tests; build them at runtime (string concatenation).
- MCP Python SDK is in v2 (`from mcp.server import MCPServer`); v1 uses `mcp.server.fastmcp.FastMCP`. Generated code supports both.
