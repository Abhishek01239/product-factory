# Product Factory run: 2026-10-07 (first scheduled run)

Decision: **BUILD**

## Selected problem
India's FEMA (Export & Import of Goods and Services) Regulations, 2026 took effect 1 Oct 2026. Every service exporter,
freelancers included, must now file an Export Declaration Form within 30 days of the end of each invoice month and realise
payment within 9 months (12 if INR). There is no threshold, and bank SOPs were still unclear in early October.

## Why selected
Brand-new, dated obligation affecting a very large group (freelancers, consultants, agencies). Visible confusion on
r/IndiaTax (thread with 132 comments; another "can someone explain" thread), BusinessLine coverage of freelancer concerns,
and trak.in/India Today explainers in the week of 1 to 7 Oct. Existing "solutions" are blog guides from fintechs.
None of the reviewed sources named a standalone tracker. Pure date logic suits a static app, so the MVP could ship
in the same run with no infrastructure.

## Scores (/10): severity 7, users 8, trend 9, competition 8, ease 9, differentiation 8, distribution 8, monetization 5, MVP speed 9 → 71/90 (7.9)
Rejected this run: AI token-cost tracker (5.7, crowded), offboarding checklist (5.6), SAC→purpose-code helper (5.6, deferred as add-on),
LibreOffice spreadsheet checker (4.8), K8s pending-pod explainer (4.7).

## Built
apps/edf-tracker: static PWA. Quick calculator, invoice log (Part 2B fields), monthly EDF batches with filed status,
realisation countdown, ₹10 lakh flag, Part 2B CSV, .ics reminders, JSON backup/restore, privacy/terms page, OG image.

## What worked
- Hand-built static app + node:test + Playwright E2E (23 checks), run against both local and live URLs.
- GitHub Pages via Actions workflow (enabled with `gh api -X POST repos/.../pages -f build_type=workflow`).

## What failed / gotchas
- Factory SEO auditor counted HTML markup for keyword stuffing (`class` flagged). Fixed to count visible text only.
- Factory security auditor flags JS `RegExp.exec(`. Avoid `.exec(` in product JS, or refine the rule later.
- Factory legal auditor expects 5 separate legal pages (AdSense-oriented); a single privacy/terms/disclaimer page was used instead.
- Social: X, Bluesky and Facebook Pages are disconnected, so launch posts were drafted only (launch/edf-tracker/posts.md).

## Signals
None yet. The product has no analytics by design. Possible signals: GitHub stars and issues, plus Pages traffic (not available via API).
