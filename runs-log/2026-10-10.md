## Built
`apps/runner-26-check/` — static, no backend, no token. Rules generated from the official 24.04 vs 26.04 image READMEs and toolset JSON (all version numbers re-verified by grep). Inputs: public repo / paste / upload; Azure Pipelines supported. Outputs: per-job verdicts with line numbers, Markdown checklist, pinned copy, side-by-side canary workflow.

## Learnings
- Dated platform migrations with an official announcement that omits details are a strong pattern (3rd product in a row built on a hard deadline). Pull the primary data (here: toolset JSON diff) instead of relying on summaries — it exposed an announcement error (Java default 17 vs 25).
- Test static analyzers against real popular repos before shipping; it caught a false positive unit tests missed.
- git in a fresh clone needs `user.name`/`user.email` set before committing.
- Distribution remains the bottleneck: 3 products live, 0 posts published. Next run should re-check social connectors first.
